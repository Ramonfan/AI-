## 后续笔记规则

以后每学习一个新技能，都按 `docs/AI应用开发流程笔记模型.md` 落地笔记。

重点不是记录“今天改了什么文件”，而是讲清：

- 这个技能在 AI 应用开发流程中处在哪一环。
- 它的上游输入和下游输出是什么。
- 它解决了什么工程问题。
- 它背后的原理和逻辑流程是什么。
- 它失败时系统应该怎么处理。
- 它在当前项目里的代码、接口和数据模型落在哪里。

# Mini AI Notes 学习路线

这条路线围绕一个小应用逐步展开。每一步都要能运行、能解释、能验收。

---

## 复习入口

阶段性复习优先看：

- `AI应用开发阶段复习笔记.md`
- `AI应用开发流程笔记模型.md`
- `ai_application_learning_knowledge_graph.html`

复习顺序建议：

```text
先看知识图谱
-> 再读阶段复习笔记
-> 用笔记模型检查每课是否说清楚流程位置
-> 最后回到具体课程和代码
```

---

## 阶段 1：先做出 iOS 壳子

目标：不接 AI，先把界面和状态流转做出来。

课程：

1. 第 1 课：做出 SwiftUI 界面
2. 第 2 课：接入 Mock 总结结果

你会学到：

- SwiftUI 页面拆分
- 输入框状态管理
- Loading / Error / Result 状态
- 结构化结果展示

阶段产物：

```text
一个不用网络也能运行的 AI 笔记总结界面
```

---

## 阶段 2：接入后端和真实模型

目标：通过后端 Proxy 调用 AI，不在 iOS 客户端暴露 API Key。

课程：

3. 第 3 课：后端 Proxy 与 AI 调用
4. 第 4 课：Structured Outputs
5. 第 5 课：iOS 解析结构化结果

你会学到：

- 后端 Proxy
- Prompt builder
- JSON Schema
- Structured Outputs
- iOS Codable 解析
- 网络错误处理

阶段产物：

```text
输入笔记后，真实 AI 返回标题、摘要、关键词、待办事项
```

---

## 阶段 3：升级为财报分析 AI App

目标：从笔记总结转向公司财报分析，建立“数据 Provider + AI 解读 + iOS 展示”的真实应用链路。

课程：

6. 第 6 课：财报分析应用转向
7. 第 7 课：SEC EDGAR 真实财报数据
8. 第 8 课：全球财报 Provider 架构
9. 第 9 课：财报分析流式输出

你会学到：

- 财报数据源和 Provider 分层
- SEC EDGAR / XBRL 基础
- A 股、港股等市场路由
- AI 分析层降级
- SSE 流式响应
- SwiftUI 流式状态展示

阶段产物：

```text
一个能读取结构化财报数据，并用 AI 生成中文解读的 iOS App
```

---

## 阶段 4：扩展到 RAG 和 Agent

目标：从“单条笔记总结”升级到“个人知识库助手”。

课程：

10. 第 10 课：扩展到 RAG
11. 第 11 课：Tool Calling
12. 第 12 课：简单 Agent

你会学到：

- 文档切片
- Embedding
- 向量检索
- RAG Prompt
- Tool Calling
- Agent Loop

阶段产物：

```text
一个能基于历史笔记问答，并能生成学习计划的小型 Agent
```

---

## 每课验收规则

每课结束都检查：

- [ ] App 或后端能运行
- [ ] 本课核心功能可演示
- [ ] 至少处理一种失败状态
- [ ] 写了学习笔记
- [ ] 能用中文讲清楚本课流程
